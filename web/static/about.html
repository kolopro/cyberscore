About CyberScore

A free, passive security scanner for domains, URLs and email — built by VortiSec.

What is CyberScore?

CyberScore is a free online security scanner that checks a website's publicly visible security configuration and produces a 0–100 score with an A–F grade. It is designed for website owners, developers and security professionals who want a quick, honest picture of a site's security hygiene without installing anything or creating an account.

Unlike invasive scanners, CyberScore performs only passive checks: it reads publicly available information — DNS records, HTTP response headers, TLS certificates — the same way any browser would. It never sends exploit payloads, does not crawl pages and does not probe internal infrastructure.

What CyberScore checks

🔒 HTTPS & TLS
Protocol versions, cipher suites, certificate validity and forward secrecy.
🛡️ Security headers
HSTS, CSP, X-Frame-Options, X-Content-Type-Options, Referrer-Policy and more.
🌐 DNS configuration
CAA records, name-server consistency and DNSSEC validation.
📧 Email authentication
SPF, DKIM and DMARC records — are they present and enforcing?
🔗 URL reputation
Phishing signals, redirect chains and multi-engine reputation lookups.
⚙️ Technology detection
Software and version disclosure that could help attackers.

Results are available in seconds, presented in plain language, with a prioritised remediation list that includes copy-ready configuration snippets. A Deep TLS tab provides an SSL-Labs-style full protocol assessment. PDF reports can be downloaded for record-keeping and sharing.

Our principles

🔍
Passive only. CyberScore never sends attack payloads, never brute-forces endpoints and never accesses anything that is not publicly visible. All findings come from information any browser or mail server could read.
🆓
Free for public use. Basic scanning is and will remain free. There is no account required. We believe security transparency should be accessible to everyone, not just those with security budgets.
📖
Actionable results. Every finding includes a plain-English explanation of the risk and copy-ready remediation steps. We don't just show you a score — we tell you exactly what to do about it.
🔐
No tracking of targets. We do not store scan results associated with your identity, do not build profiles of scanned domains and do not share data with third parties beyond what is needed to perform reputation lookups. See our Privacy Policy for the full picture.
🌍
Bilingual. CyberScore is available in English and Greek — because good security information should be available in more than one language.

Who built it

CyberScore is built and maintained by VortiSec, a small security-focused software company. VortiSec develops security tooling with an emphasis on passive, non-invasive approaches that can be used safely against any public infrastructure without prior authorisation.

How to use CyberScore responsibly

CyberScore is a passive tool, but we still ask that you use it ethically:

  • Scan domains you own, or domains you have been authorised to test.
  • Do not attempt to use the scanner to map or probe internal infrastructure.
  • If you find a vulnerability in a site via CyberScore, follow responsible disclosure — notify the site owner before making any findings public.

Automated bulk scanning via the API for research or monitoring is acceptable, but please keep request rates reasonable so the service stays fast for everyone.
